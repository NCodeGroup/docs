## Seal a secret

`Vault.Rent` hands back a pinned buffer and its owner. Disposing the owner zeroes the whole buffer, so the key never
outlives the method.

```cs snippet=QuickStart title="QuickStart.cs" {4}
```

:::note
`Rent` hands back a span sliced to exactly the length you asked for, even when the buffer behind it is larger.
:::

:::caution
There is no finalizer. A vault that is never disposed is never zeroed, so always use `using`. The
[guide to deriving a key](/guides/derive-a-key/) shows the whole pattern.
:::

## Choosing an API

Every row is a member of `Vault`.

| API | Use it when | Pooled |
| --- | --- | --- |
| `Rent` | You need a temporary buffer for a key or a password | Yes |
| `RentKey` | You need exactly 32 bytes | Yes |
| `Wrap` | You already have the memory, usually `stackalloc` | No |
