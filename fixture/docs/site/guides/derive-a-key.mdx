import { LinkButton } from '@ncodegroup/docs/components';

A derived key is as sensitive as the password it came from. Derive it straight into a vault, never into an array of
your own.

```cs snippet=DeriveKey
```

The salt is not a secret, so it lives on the stack without a vault. The same key, sealed behind a method, is the
[quick start](/quick-start/#seal-a-secret)'s sample.

:::tip[Iterations]
600,000 iterations of PBKDF2 with SHA-256 is the figure OWASP recommends; see the
[password storage cheat sheet](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html).
:::
